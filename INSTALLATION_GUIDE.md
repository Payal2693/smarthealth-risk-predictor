Installation Guide

1. Prerequisites
Before running the project, make sure you have installed:
Python 3
Git
Visual Studio Code or another code editor

2. Download the Project
Clone the repository using:
git clone https://github.com/Payal2693/smarthealth-risk-predictor.git

Move into the project folder:
cd smarthealth-risk-predictor

3. Install Dependencies
Install the required Python libraries:
pip install -r requirements.txt

4. Run the Application
Start the Flask application:
python app.py

5. Open the Application
Check the terminal for the local development address displayed by Flask. Open that address in your web browser.

6. Troubleshooting
Python not found: Check whether Python is installed and added to PATH.
Module not found: Run the dependency installation command again.
Application not opening: Check the terminal for errors and confirm that the Flask application is running.
