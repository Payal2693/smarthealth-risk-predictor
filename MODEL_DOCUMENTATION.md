Machine Learning Model Documentation

1. Overview
SmartHealth Risk Predictor uses machine learning to provide basic screening for heart disease and diabetes. It uses two separate Random Forest classification models.

2. Heart Disease Prediction
The heart disease model uses health-related parameters such as:
•	Age
•	Sex
•	Chest pain type
•	Resting blood pressure
•	Cholesterol level
•	Maximum heart rate
•	Other clinical attributes
The model processes the provided values and predicts the heart disease risk category.

3. Diabetes Prediction
The diabetes model uses relevant health information provided by the user to estimate the likelihood of diabetes.
It works independently from the heart disease model.

4. Algorithm Used:-Random Forest Classifier
Random Forest is a supervised machine learning algorithm that combines predictions from multiple decision trees to produce a final classification.

5. Model Workflow
  1.	Collect the dataset.
  2.	Prepare and preprocess the data.
  3.	Train the Random Forest model.
  4.	Evaluate the model.
  5.	Use the trained model to generate predictions from user inputs.
  6. Prediction Output
The application displays the prediction generated by the corresponding model based on the information entered by the user.

7. Limitations
•	Predictions depend on the quality of the training data.
•	Results are intended for educational screening purposes.
•	The system cannot replace medical testing or professional diagnosis.

8. Conclusion
The project demonstrates how machine learning models can be integrated into a web application to support basic health risk screening.
